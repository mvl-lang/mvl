# AGENTS.md has moved

The canonical AGENTS.md template for MVL projects now lives at
[`mvl-lang/mvl-spec/agents/AGENTS.md`](https://github.com/mvl-lang/mvl-spec/blob/main/agents/AGENTS.md).

Moved because the content — the syntax reference, the 11 compiler-verified
requirements, the language cheat sheet — defines what MVL *is*, which per
`mvl-spec`'s own README belongs with the spec it must stay consistent with,
not with the compiler implementation. See `mvl-spec` CHANGELOG (Unreleased)
and README §What lives here vs. in the compiler repo.

Copy the file from its new location into the root of any MVL project
(eventually done automatically by `mvl new`).
